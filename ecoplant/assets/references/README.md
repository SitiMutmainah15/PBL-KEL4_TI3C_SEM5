# Foto referensi

Dua belas foto contoh dipakai sebagai pembanding visual pada layar hasil, tiga per kelas.

Sumber: `training/dataset/test/<kelas>/`. Foto diperkecil ke sisi terpanjang 448 px dan
dikompresi JPEG agar paket aplikasi tetap kecil. Berkas asli tidak diubah.

Foto ini hanya pembanding tampilan, bukan bagian dari keluaran model dan tidak dipakai
untuk menghitung confidence.
